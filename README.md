# Fashion Website – MTM6201 Midterm

A responsive fashion shopping website created using HTML and CSS. The website includes three pages: Home, Catalogue, and Lookbook.

### Built With
- HTML
- CSS
- Flexbox and CSS Grid
- Google Fonts (Poppins)

### Features
- Responsive design for mobile and desktop
- CSS animations and transitions
- Responsive images
- Navigation between three pages
